Point an axe, shovel, hoe or honeycomb at a block and this JEI category shows what that block will become, including blocks added by other mods.

## What it lists

- **Logs and wood** — axe stripping, including modded wood such as Biomes O' Plenty's fir.
- **Copper** — scraping oxidation, removing wax, and waxing with honeycomb.
- **Soil** — shovel paths and hoe tilling.
- **Every tool that works** — each row cycles through all items that can perform the action, so modded axes and hoes appear next to vanilla ones.

## How to use

Open JEI, find a block, and press **U** to see what right-clicking does to it. Press **R** on a result block to see what produces it. Each row is source block + held item → result block; there is no separate search field.

## What is not listed

Only tool actions that the game exposes through its block transformation hooks are included. Right-clicks handled inside a block's own use code — pumpkin carving, bone meal, brushes, buckets, and similar — are not listed. A mod's transformation appears only when that mod registers it through the vanilla or NeoForge tool hooks; a right-click implemented directly in the block's use method will not appear even if the block is installed.

The list follows the blocks present in your game rather than a fixed table. Rows that only change block state (a campfire going out, a plant being trimmed) and blocks without an item form are left out, because JEI would show the same icon before and after.

Requires JEI for Minecraft 1.21.1 on NeoForge, version 19.57.0 or later. Client side only.

The debug dump is off by default. Set `debugDump` in the client config to write `config/justenoughrightclicks-dump.txt`.
